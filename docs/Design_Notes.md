# Serial Tap Logger | RS-232C Rev.1 設計資料

## 電圧校正用の表面パッド

| パッド | 信号 | DE-9のピン |
|---|---|---:|
| TP7 | TXD | 3 |
| TP8 | RXD | 2 |
| TP9 | RTS | 7 |
| TP10 | CTS | 8 |
| TP11 | DTR | 4 |
| TP12 | DSR | 6 |
| TP13 | DCD | 1 |
| TP14 | SG（基板GND） | 5 |

上ぶたを外して、校正用DC電源とマルチメーターの赤を対象線のパッド、黒をTP14に接続する。RIは比較器入力のみ。TP8はWeAct A1と電源モジュールPS1の間にある。表面パッド8点の接続と座標を入稿用Gerberに反映した。[ピン照合表](Pin_Mapping.csv)・[製造・部品手配](Manufacturing.md)

[回路図（全3頁）](Serial_Tap_Logger_RS232C_Rev1.pdf) ／ [製造・部品手配](Manufacturing.md) ／ [README](../README.md)

Rev.1はRS-232Cを対象とする。計画するロガーは8線の変化を共通の時計で記録し、PC側で通信プロトコルを解析する。ログの開始日時にはU12のPCF8563Tを使用する。

KiCad 10用のキャリア基板。外形100 × 100 mm、2層、板厚1.6 mm。表面（F.Cu）が操作面。DE-9は左右の対向辺、USB-C・microSD・DCジャックは同じ辺からアクセスする。J1（DE-9オス）とJ2（DE-9メス）は全9ピンを同番号で直結する。5番のSGは回路GND。シェルはSHIELDで直結し、R66の未実装時は回路GNDと分離する。D-subのSG、DCジャックの負極、USBのGNDは共通。**測定中はUSBでPCに接続しない。** 丸形ジャックから出力がフローティングの安定化12 Vアダプターで給電する。PCから時刻設定・書き込みを行うときは、先に両側のDE-9を外す。

## RTCとバックアップ電源

U12はPCF8563T（C7440、SO-8、I²Cアドレス0x51）を裏面に実装する。Y1は秋月104005のVT-200-F（32.768 kHz、12.5 pF、ESR最大50 kΩ）を表面に直立させて手はんだする。リードは封止部から離れた位置で1.27 mmピッチに成形し、φ0.55 mmの穴2つに挿す。金属ケースがランドに触れないよう基板面から約2 mm浮かせ、裏面のリードは基板下面から0.8 mm以内に切りそろえる。Y1直下の両層に銅箔ゾーン・ビアの禁止領域を設けた。OSCI（U12の1番ピン）とGNDの間にC31（22 pF、C0G、±5%）を接続する。OSCO側にはPCF8563Tの内蔵容量を使う。試作機で発振開始と時刻の進みを確認する。SDA（GP20）とSCL（GP21）はR59・R60（各3.3 kΩ）で3V3へプルアップする。~{INT}とCLKOUTはオープンドレインで未接続。[秋月104005](https://akizukidenshi.com/catalog/g/g104005/)

電源は3V3 → D1（BAT54X、C19627026）→ RTC_VBAT（U12のVDD、C28 100 nF）。RTC_VBATからR67（1 kΩ）を通してC27の＋へつなぐ。3V3がある間はC27を約3.0 Vまで充電し、3V3が切れるとC27がR67経由でU12を保持する。D1は逆漏れの小さいショットキーを選んだ（1N5819WSは逆漏れが大きいため不可）。C27が空のときの充電電流は約3 mA。時定数はR67×C27で約25分、95%充電まで約75分。

C27は秋月104250（SE-5R5-D155VY、1.5 F、定格5.5 V）。角パッドが＋。LCDの下に平置きし、キャリアからの浮きを0.5 mm以内にする。J4ソケットの高さは8.5 mm。LCD基板下面までの設計すきまは2.64 mm以上。

保持時間はPCF8563の消費電流0.25〜0.5 µAだけで見積もると、3.0 Vから約1.3 Vまでで1〜2か月。実際はC27の自己放電が支配的で、これより短い。試作時は満充電後に無給電で72時間保持して確認する。C27の電圧を測る回路はない。[秋月104250](https://akizukidenshi.com/catalog/g/g104250/)

## DCジャック給電

DCジャックは安定化12 V専用、USB-Cは5 V。

J6は秋月106568（MJ-179PH）。安定化DC 12 V、外径5.5 mm・内径2.1 mm、センタープラス。J6の1番が＋、2番がGND、3番はスイッチ接点で未接続。プラグの抜き差しはケースに基板を固定して行う。

J6 → D2（SS34、逆極性保護、降下約0.4 V）→ DC_IN（C22 22 µF／50 V、C24 22 µF／25 V）→ PS1（秋月BP5293-50、入力7〜26 V、出力4.9〜5.1 V、最大1 A、UVLO 6.0〜6.8 V）→ BUCK_5V → Q3（AO3401A）→ 5V_A／WeAct H1.2。

Q3のゲートはWeActのH1.1（USBの生VBUS）に直結し、R68（100 kΩ）でGNDへ引く。USBありではゲートがVBUSになり、WeActのVBUSと5Vの間は理想ダイオードIC（WeAct回路図のU2）なので、5V_AはVBUSとほぼ同じ電圧になり、VGS ≈ +0.05 V。AO3401AのVGS(th)は−0.5 V以下なのでQ3はオフ。BUCK_5VへのUSBの逆流をQ3が止める。USBなしではゲートが0 Vに引かれ、VGS ≈ −5 VでQ3がオンし、降下は数十mV。DCとUSBを同時に挿すとQ3のボディダイオード経由でも給電され、並列になる。USB-C側はWeAct内蔵のVBUS逆流防止経路（理想ダイオードIC）を使う。WeActの回路図にはU2をまたいでVBUSと5Vを直結するジャンパーパッドがある。ここが短絡していると、DC給電時にUSBホストへ逆流し、Q3の切替も働かないので、受入時に開放を確認する。アダプタ負極、USB GND、D-sub 5番は共通。

PS1はSIP3・2.54 mmの挿入部品で、表面に直立させて手はんだする。穴径はφ1.2 mm、ランド径はφ1.6 mm。基板から0.5 mm浮かせた組立CADで、ケースとの最小すきまは1.7 mm。実物での挿入と嵌合は試作時に確認する。[寸法の確認記録](Work_Status.md)

C22は秋月108156（22 µF／50 V、表面手はんだ）。無極性。5 mmピッチのリードを曲げ、WeActの下でシルクに沿って横倒しとし、部品底面の浮きは0.35 mm以下とする。24 V常用や誤挿入時の基板全体の保護は保証しない。

試作評価は12 Vジャック単独、USB単独、USBとの同時接続・抜き差しで行う。液晶最大輝度＋microSD書込み時にTP1（5V_A）が入力判定の計算範囲4.50〜5.25 Vに収まり、TP2（3V3）とロガー動作が安定することを確認する。12 V入力時のリップル・誤検出・発熱、DC単独時のUSB VBUS側とUSB単独時のジャック側への逆流、ジャックのプラグ嵌合、PS1の高さとケースの干渉は実機未評価。

部品資料は [ジャック](https://akizukidenshi.com/catalog/g/g106568/)、[BP5293-50](https://akizukidenshi.com/catalog/g/g111188/)、[WeAct回路図](https://github.com/WeActStudio/WeActStudio.RP2350BCoreBoard/blob/main/HDK/RP2350B_SCH.pdf)。

## 入力回路

各線を100 kΩ 2本直列で分岐し、節点から6.8 kΩを共通バイアスBIASへ接続する。独立分圧案では開放節点と上側基準の公称差が5 V時に約33 mVで、1%抵抗の組み合わせで逆転する。このためLM358で電源の1/3をバッファし、8chのバイアスと上下基準を同じBIASから作る。ADC7でBIASそのものを測る。±3 Vの入力を電源変動時にも判定できるよう、上側基準VHIはR43 100 kΩ／R44 750 Ω、下側基準VLOはR45 820 Ω／R46 10 kΩで設定する。

| 5V_A = 5.00 V、抵抗公称値 | 計算値 |
|---|---:|
| 線路側の入力抵抗 | 約206.8 kΩ |
| 線路 −25 V / 0 V / +25 V の節点 | 0.790 / 1.612 / 2.434 V |
| 開放時の節点 | 1.667 V |
| TP5（VHI） / TP6（VLO） | 1.691 / 1.540 V |
| 上側 / 下側の判定点（線路換算） | +2.42 / −2.17 V |

k = 6.8 / 206.8。線路電圧の推定式は **Vline = Vbias + (Vnode − Vbias) / k**。電源4.50〜5.25 Vと各抵抗の公差±1%を含めると、線路換算の判定点は上側+2.14〜+2.59 V、下側−2.47〜−1.80 Vとなる。開放時の比較器入力とVHIの差は最小約21.7 mV。これらはICのオフセット、入力電流、ADC漏れ、寄生容量を除いた計算値である。

上下出力POS/NEGの10は正、01は負、00はしきい値内。開放と0 V駆動を電気的に識別するものではない。データ線では窓内を通過する間は直前の符号を保持する。±25 Vを通電時の評価範囲とし、±50 V耐圧・ESD耐量は規定していない。

## GPIO

| 用途 | 接続 |
|---|---|
| 比較器 | TXD、RXD、RTS、CTS、DTR、DSR、DCD、RIの順。GP1/2からGP15/16まで、各組はPOS、NEG。PIO入力ベース1 |
| microSD | CLK GP34、CMD GP35、DAT0〜3 GP36〜39。カード検出GP17は装着時Low。SPI0ではSCK GP34、MOSI GP35、MISO GP36、ソフトウェアCS GP39 |
| RTC（U12）・記録 | SDA GP20、SCL GP21、EC11押し込みGP18で記録操作 |
| 拡張（Grove） | J7はI²C（GP20/GP21をRTCと共用）。J8はGP22・GP24をR69・R70（各100 Ω）経由で出す |
| 表示器SPI1 | SCK GP26、MOSI GP27、DC GP28、CS GP29、RES GP30、BL_PWM GP31。表示器内蔵NPN（BLK→1 k→ベース、10 kでVCCへプルアップ）をR58（10 Ω）経由で直接駆動。Highで点灯、PWM7 Bで明るさ調整。リセット中は点灯 |
| 操作 | A GP32、B GP33、PUSH GP18、K0 GP19 |
| ADC0〜7 | GP40〜46はTXDからDCDまでの7節点、GP47はBIAS。RIは比較器の状態のみ |

WeActのH1・H2は各2×15。二次Flash/PSRAMのCSと共用のGP0、基板キーのGP23、基板LEDのGP25はキャリアから駆動しない。GP23はハードI²C1でGP22と組めるが、基板キーが付いているので使わない。5V_AはH1.2の5V端子で、USBの生VBUS（H1.1）と区別した。J3は信号列1×10と支持用の1×2が左右に各1列。付属1×14の細ピンヘッダを10極と2極2本に分ける。TP1から順に5V_A、3V3、GND、BIAS、VHI、VLO。

## Grove拡張

前辺のUSB-Cの真下、WeActの下に Seeed 110990037（Grove 4ピン L型、秋月112634）を2個並べた。J7はI²C、J8はGP22・GP24。USB-Cの中心線（X = 160.9 mm）から左右対称で、J7の中心は (155.15, 153.6)、J8は (166.65, 153.6) mm。コネクタの口は基板端から3.5 mm前に出て、奥行111.5 mmのケースの前面とそろう。ピン列は基板端から4.6 mm内側。本体の高さ5.0 mmに対し、WeAct基板の下面は約8.2 mm（裏面のPSRAMを実装しても約6.4 mm）で干渉しない。WeActより先にはんだ付けする。

| 端子 | J7（I²C） | J8（IO） |
|---|---|---|
| 1（黄） | SCL（GP21） | GP22（R69経由） |
| 2（白） | SDA（GP20） | GP24（R70経由） |
| 3（赤） | 3V3 | 3V3 |
| 4（黒） | GND | GND |

電源は3.3 V固定。I²CのプルアップはR59・R60（各3.3 kΩ）を共用し、RTC（0x51）と重ならないアドレスの機器をつなぐ。外部プルアップなしでバス容量が100 pFの場合、立ち上がり時間の計算値は約280 ns。GP22・GP24はハードの組を作れないため、UARTや2本目のI²CはPIO2で実装する。J8の直列抵抗は短絡と静電気の保護用で、ESD素子は載せていない。外部から5 Vを加えない。

前辺にあったGNDの補助配線（A1.4〜A1.31間）はJ7・J8のピンと重なるため外し、GNDは両面のベタで接続する。USB_VBUSとDC_INの前辺の配線は引き直した。

## SDHCの高速記録

秋月AE-MICRO-SD-DIPを3.3 Vで使う。J3の1、2、3、5、7、8番は順にDAT2、DAT3、CMD、CLK、DAT0、DAT1。4番は3V3、6番と10番はGND、9番はカード検出。CMDとDAT0〜3はR47〜R51の各10 kΩで3V3へプルアップする。[秋月の端子図](https://akizukidenshi.com/goodsaffix/K-5488_AE-MICRO-SD-DIP.pdf)

J3はキャリア側の10極ソケットで着脱する。CLKの5番と、カードのVSSにつながるGNDの6番は隣接する。キャリア側は6番の近くに表裏GNDの接続ビアを配置した。ファームウェアのSDクロック設定は24 MHz。仮組み時に、6番からカードソケットのVSSまでの導通とカード口の位置を確認する。

カード口側は、秋月の基板図10ページに示された2.54 mm配置の内側4穴を使って支持する。キャリアの支持穴はφ1.02 mmのめっきスルーホールで、ランド径は1.60 mm。4穴とも信号・電源から絶縁する。カード口側の2極ソケット2本を信号側ソケットと同じ高さに並べ、モジュールが水平でカードが開口に当たらないことを仮組みで確認してからはんだ付けする。[秋月の基板図](https://akizukidenshi.com/goodsaffix/AE-MICRO-SD-DIP_plot.pdf#page=10)

4ビット動作ではPIO1をSD専用に使い、GPIOベースを16とする。データ線を連続するGP36〜39に置き、CLKをDAT0の2ピン手前に置いた。RS-232Cの比較器はPIO0で取り込める。GP38・39はSD専用となり、GP36・37を使うRS-485受信案との同時使用には別の割り当てが必要。[4ビットSDドライバの設定例](https://github.com/inindev/pico-fatfs-sd)

RS-232CのTXDとRXDが各115,200 bpsで毎ビット反転し、符号が変わるごとに8バイト記録する仮定では、必要書き込み速度は1,843,200 B/s。制御線イベントとファイル管理情報は別。32 KiBのブロックは約17.8 msでたまる。256 KiB全体の保持時間は約142 msで、書き込み中の1ブロックが占有する場合の残り224 KiBは約124 ms分。平均速度とカードが応答しない最長時間を実機で評価する。

### カード単体の試験

採用カードでの欠落評価は、TXD・RXDの連番パターンを同時入力して行う。

## 記録ファームの実装要件

比較器にヒステリシスがないため、PIOで捉えた正負判定の数百ns以内の再反転を抑制する。採用する時間幅は実入力で設定し、正規のエッジに対する時刻誤差と取りこぼしを測る。ADC入力GP40〜47はデジタル入力を無効にする。これらは記録ファームの要件で、カード試験用UF2の評価対象はSD書き込みと読み戻し。

RTCはPCF8563（0x51）。起動時に秒レジスタ（0x02）の最上位ビットVLを読み、1なら時刻を無効として液晶に「時計未設定」と表示し、USBから時刻を設定させる。設定時にVLは0に戻る。CLKOUTは使わないので制御レジスタ0x0DのFEを0にする。

## 試作で確認する点

- エンコーダ共通端子からJ4.1（GND）への導通。RTCは無通電でC27の極性とD1・D2の向きを照合する。充電後にUSBとDCを両方外し、72時間後に再給電して日時を確認する。

- AliExpress表示器の端子順、取付穴、BLKの回路と電流、コントローラ。モジュール高さとUSB・カードの抜き差しは現物で確認する。表示器の4穴位置は参考図による。
- 秋月D-subの固定金具、シェルからSHIELDランドまでの導通、オス・メス両側のピン1。無通電で全9線の導通と隣接ピンの絶縁を確認する。
- 8線を開放して誤検出がないことを確認し、各線に−3 Vと+3 Vを順に加えて負・正の判定を確認する。TXD・RXDには±3 V、115,200 bpsの連続 `0x55` を入力し、記録した両方向のバイト列を送信値と照合する。
- 実装したWeActのチップリビジョン、無給電時の入力電流・電源レールへの回り込み、microSD書込み時の3V3、ADC搭載7線の開放・±3 V境界・±25 Vでの電圧値を確認する。制御線同時変化、µs記録・SD保存・プロトコル解析の動作はファームウェアと実機での評価項目。
